How to Start & Initialize MySQL:

  1. Start MySQL Server:

    Via Windows Services: Press Win + R → services.msc → Start MySQL80.

    Or via Docker:

    docker run -d -p 3306:3306 --name library_mysql -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=LibraryDB mysql:8.0
  2. Import Schema & Sample Data: 
    mysql -u root -p < database/schema.sql
mysql -u root -p < database/sample_data.sql

    Or open MySQL Workbench 8.0, connect to Local instance, and execute database/schema.sql and database/sample_data.sql.
